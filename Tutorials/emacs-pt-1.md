# Dummy's Guide to Emacs Part 1— Installing and Getting to Gripes with Janky 80s Tech
## What _is_ Emacs? 
Well, Emacs is an 80s text editor by definition. But with that definition comes with _a lot_ of baggage. It really isn't a text editor in the same way that a hot dog isn't a sandwich— by many definitions, that's true, but as with a hot dog, the difference is on the inside.
### Emacs is a programming language, sort of
Emacs is written in C++, which is a very much convoluted language not comprehensible by anyone other then _major_ geeks. But on top of that C++ layer is another extension language named _Emacs Lisp_, commonly abbreviated Elisp.
